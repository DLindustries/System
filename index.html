Installation Guide

Get System up and running in four simple steps.

1

Download System Client

Get the latest JAR file from our GitHub releases page.

2

Install Fabric

Install Fabric Loader for Minecraft 1.21 / 1.21.1 and Fabric API.

3

Add to Mods Folder

Move the System JAR file into your Minecraft mods folder.

4

Launch & Configure

Start Minecraft with Fabric Loader, press Right Shift to open the GUI and configure System for your target servers.
